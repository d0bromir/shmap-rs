4. the control: what plain defaults do
---------------------------------------
No preset at all, on the same reads and the same index. This was meant to
isolate the fault to the long-read preset path, on the reasoning that if
the default path survives then neither the index nor the reads are at
fault. IT DOES NOT SURVIVE. Plain defaults segfault on these reads too, on
both architectures, so the fault is not specific to -x. What does survive
is a small enough batch: 20 reads with no preset is fine, which is how an
earlier version of this note came to claim x86_64 survived the control at
all. It was reading a sample below the threshold.
