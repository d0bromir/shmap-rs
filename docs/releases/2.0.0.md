# 2.0.0: Adaptive placement retired

A MAJOR release because CLI flags were removed. **Default-mode PAF output is
unchanged from 1.6.0**, and the original mapper remains the only mapping algorithm.

## Breaking

- `--adaptive` and `--adaptive-dense` now fail explicitly, in the CLI and in library
  calls. They were opt-in experimental modes introduced in 1.6.0; fixed-window sampled
  placement failed truth-based accuracy qualification
  ([study](../../benchmarks/results/adaptive-mapq-442928c/README.md)) and is not
  available in production. Historical reproduction requires the measured revision.

## Kept

- `--compact-index`, `--index-cache`, `--verify-index-reference`, `--read-batch-size`,
  `--reader-threads`: output-preserving, unchanged.

## Changed

- k-mer hashing sits behind a `KmerHasher` trait; sketching code simplified.
- Native candidate verification optimizations (setup-time gain; mapping time roughly
  flat — [validation](../../benchmarks/results/native-compare-6e33e5c/README.md)).
- Documentation reorganized: `docs/` index, result-set index, tighter READMEs, and a
  link checker in CI. See [`docs/README.md`](../README.md).

## Evidence

- Default-mode spot checks versus historical C++ at `e71ca0f`: 2.34-2.46x (a2),
  2.16-2.34x (galaxy) total time, one worker; single runs, C++ not rerun
  ([report](../../benchmarks/results/supported-e71ca0f/README.md)). The 10x target is unmet.
- Rejected screen: repeat-factored shadow search
  ([report](../../benchmarks/results/repeat-factored-shadow-e71ca0f/README.md)).
- Direction: accuracy first, Winnowmap2 as target — [`docs/ROADMAP.md`](../ROADMAP.md).
